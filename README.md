# Project 04: Learning Management System (ACADEMIA)

A collegiate university learning portal and curriculum management system built with **React + Vite + TailwindCSS + Zustand** simulating **Firebase Auth, Firestore & Storage**.

## 🎨 Distinct Visual Identity
- **Palette**: Academic Navy (`#102a43` / `#0b1d3a`) and crisp white with regal gold accents (`#d4af37`).
- **Typography**: Editorial serif headings (`Lora` & `Cinzel`) paired with clear contemporary sans-serif.
- **Layout**: Collegiate sidebar-driven campus portal with student progress dials and lecture media players.

## 🚀 Full Feature Set Included
- **Course Builder with Modules & Lessons**: Supports structured modules with video players and downloadable PDF monographs.
- **Progress Tracker & Completion Metric**: Real-time completion percentage with dynamic progress bar.
- **Auto-Generated Official Certificates**: Generates and downloads verified university completion diplomas with cryptographic seals.
- **Interactive Quizzes with Auto-Grading**: Real-time evaluation and scoring with instant scholastic feedback.
- **Course Discussion Forum**: Peer-to-peer scholarly discourse feed with replies and thread creation.
- **Faculty Studio & Drop-off Analytics**: Metrics for matriculated scholars, completion averages, and syllabus drop-off nodes.
- **AI Course Cover Thumbnail Generator**: Automated generation pipeline for faculty publishing courses without custom media.
- **Role Switcher**: Seamlessly toggle between **Student Scholar** and **Faculty Instructor** roles.

## 🛠️ How to Run
```bash
npm install
npm run dev
```
